# 分析チェックリスト（口座別・毎週）

各口座について、**直近7日 vs 前7日**（および可能なら**目標値**）で比較し、下の閾値に触れたものを「異常」として拾う。
拾った異常ごとに **原因仮説 → 推奨アクション** を1行で書き、`account-tracker.csv` に記入する。

---

## STEP 1. 数値を集める（監視）

Google Ads（口座 or キャンペーン単位）:
- Cost（費用）
- Impressions / Clicks / CTR
- Avg. CPC
- Conversions / CVR / CPA
- Impression Share（検索広告のインプレッションシェア）と "lost IS (budget)" / "lost IS (rank)"
- Search terms（検索語句）— 無駄クエリの混入
- Ad status（不承認・停止がないか）

GA4:
- 該当LPのセッション数 / エンゲージメント率 / コンバージョン
- 流入直後の直帰・離脱（フォーム到達率など）

Viewtrace（← 独自価値。ここが差別化）:
- 出稿先LPの**スナップショット**：崩れ / 404 / リダイレクト / 価格・在庫表示の変化 / 主要CTAの消失
- 「広告は回っているのに成果が落ちた」時、**"実際に表示されていた画面"の記録**で原因を切り分ける

---

## STEP 2. 異常検知の閾値（目安・口座に合わせて調整）

| 兆候 | 閾値の目安 | 重大度 |
|---|---|---|
| CPA 悪化 | 前週比 **+30%** 以上 | 高 |
| CVR 低下 | 前週比 **−25%** 以上 | 高 |
| 費用増だが成果横ばい | Cost **+40%** かつ Conv ほぼ変化なし | 高 |
| クリックあるがCV=0 | クリック **≥ 通常の1日分** で Conv 0 が継続 | 高 |
| インプレッションシェア喪失 | lost IS(budget/rank) が **+15pt** 悪化 | 中 |
| CTR 急落 | 前週比 **−30%** 以上 | 中 |
| 広告不承認 / 配信停止 | 1件でも発生 | 高 |
| **LP異常（Viewtrace）** | 404 / 大幅な表示崩れ / CTA消失 / 価格変化 を検知 | 高 |
| 無駄クエリ混入 | 上位検索語句に無関係語 | 中 |

> どれも「厳密な正解」ではなく **狼少年化を避ける**ための入口。触れたものだけ深掘りする。

---

## STEP 3. 原因仮説 → 推奨アクション の型（よくあるパターン）

| 観測された異常 | 原因仮説（例） | 推奨アクション（例・操作は代理店が承認/実行） |
|---|---|---|
| CV=0 だがクリックは正常 | LP崩れ / フォーム不具合 / 404（Viewtraceで確認） | LP復旧を最優先。復旧まで配信一時停止を検討 |
| CPA +30% / CVR −25% | LP内容変更・在庫切れ・価格改定 | 変更点の巻き戻し or 訴求とLPの整合を取る |
| 費用+40%・成果横ばい | 入札/予算の自動調整の暴れ・無駄クエリ増 | 除外キーワード追加、入札上限の見直し |
| CTR急落 | クリエイティブ疲弊 / 競合の新広告 | 広告文の差し替え・新パターン投入 |
| IS(rank)悪化 | 品質スコア低下・競合の入札上昇 | LP関連性・広告文の改善、入札見直し |
| 広告不承認 | ポリシー違反・LP文言 | 該当箇所修正して再申請 |
| 無駄クエリ混入 | 部分一致の広がり | 除外キーワード追加・マッチタイプ調整 |

---

## STEP 4. 重大度でトリアージ（配信に載せる順）

- **要対応(High)**：今日中に手を打つべき（成果に直結・機会損失中）→ レポート冒頭に
- **注視(Watch)**：悪化の初期兆候。来週も観察
- **正常(OK)**：異常なし。1行で「問題なし」と伝える（安心も価値）

→ ここまでを `account-tracker.csv` に記入し、High/Watch を `weekly-report-template.md` に転記する。
