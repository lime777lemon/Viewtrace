# 週次レポート雛形（代理店に見せる成果物）

「異常 → 原因 → 推奨」の**3点セット**で、要対応の口座だけを短く伝える。
数値は必ず **今週 / 前週（or 目標）** を併記。原因は可能なら **Viewtrace の記録リンク**で裏づける。

- 送付は水曜。長くしない（読むのに3分）。
- 「操作」はしない。推奨まで。実行は代理店が判断。

## 書き方のコツ
- **要対応を最初に、多くて3件**。全部書くと読まれない。
- 数値は必ず before → after。「なんとなく悪い」は書かない。
- 原因は**証拠**とセット。Viewtrace の記録リンクが最も強い（"実際にこう表示されていた"）。
- 推奨は**1手**に絞る。「あれもこれも」は判断を止める。
- 正常口座も1行で触れる＝「毎日見なくて済む」安心を提供＝これが購入理由。
- **必ず「お客様には目安として」提示する**。提供範囲は①監視〜④推奨まで（アドバイザリー）。
  実際の広告操作（⑤）は行わない＝末尾の免責文を毎回入れる。
